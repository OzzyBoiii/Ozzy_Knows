      Privacy, keyboard, and hosting
      

        
What leaves this device: (1) HTTPS requests to your chosen AI API base URL when you click Generate — prompt, model, and API key header. (2) Browser requests to cdn.jsdelivr.net for KaTeX, MathLive, and MathJax (when used). Nothing is sent to the author of this file; there is no built‑in analytics.

        
Secrets: API keys are stored in localStorage on this origin only. Any script on the same origin could read them — do not host untrusted pages alongside this tool.

        
Keyboard: Ctrl+Enter in the AI prompt runs Generate. Alt+L toggles LaTeX source visibility (when focus is not in a text field). Esc closes overlay windows.

        
Opening the file: Use a local HTTP server (see README.md in this folder) for the most predictable behavior; file:// may limit modules or fetch. Current Chromium, Firefox, and Safari generally work; use an up‑to‑date browser.

        
Add ?debug=1 to the URL for extra console logs. Add ?test=1 to run built‑in self‑checks (see console).

        
Extension hooks (advanced): assign window.latexToolHooks = { beforeExport(bundle) { … }, afterRender(info) { … } } before using Export or after load — useful for custom logging or transforms.
