## 🚀 ADDITIONAL MUST-HAVE PLUGINS

### 1. **Multi-Column Markdown** ⭐⭐⭐⭐⭐
**What it does**: Create side-by-side columns in notes

**Syntax**:
````markdown
```multi-column
Column 1 content here
```column-break
Column 2 content here
```column-end
````

**Use cases**:
- Comparison tables
- Before/After layouts
- Side-by-side translations
- **SOLVES your text-left/visual-right need!**

**Installation**: Community Plugins → Search "Multi-Column Markdown"

---

### 2. **Kanban** ⭐⭐⭐⭐⭐
**What it does**: Visual task boards (like Trello)

**Usage**:
- Create board: Command Palette → "Kanban: Create new board"
- Drag tasks between columns
- Track study progress visually

**Perfect for**:
- Study planning
- Project management
- Assignment tracking

---

### 3. **Obsidian Git** ⭐⭐⭐⭐⭐
**What it does**: Auto-backup vault to GitHub

**Why you need it**:
- Never lose notes
- Version history
- Sync across devices
- Free unlimited backup

**Setup**:
1. Create GitHub repository
2. Install plugin
3. Configure credentials
4. Auto-commits every X minutes

---

### 4. **Commander** ⭐⭐⭐⭐⭐
**What it does**: Add custom buttons anywhere

**Features**:
- Add buttons to ribbon
- Add to title bar
- Add to status bar
- Quick access to commands

**Example**: Button for "Insert Cornell Template" in ribbon

---

## ⚠️ WARNINGS

### Don't Install:
- ❌ Too many plugins at once (slow performance)
- ❌ Redundant plugins (e.g., 3 calendar plugins)
- ❌ Abandoned plugins (check last update)
- ❌ Conflicting plugins (e.g., 2 task managers)

### Best Practices:
- ✅ Install one at a time
- ✅ Test each plugin
- ✅ Read documentation
- ✅ Keep plugins updated
- ✅ Remove unused plugins

**Minimal Impact** (always safe):
- Linter
- Editor Syntax Highlight

- Templater

- Calendar

**Moderate Impact** (monitor):
- Dataview
- Excalidraw

- PlantUML

**Heavy Impact** (use sparingly):
- Obsidian Git (on large vaults)
- Multiple sync plugins
- Complex Dataview queries
- Many custom JS scripts
