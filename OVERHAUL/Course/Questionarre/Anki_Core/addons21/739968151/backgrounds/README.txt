BACKGROUND IMAGES FOLDER
========================

Place your background images here for use in Universal Beautify Anki.

RECOMMENDED SPECIFICATIONS:
- Resolution: 2560x1440 pixels (for lossless scaling)
- Format: PNG, JPG, JPEG, or WEBP
- File size: Keep under 5MB for best performance

HOW TO USE:
1. Copy your background images to this folder
2. Open Theme Designer (Visuals → Theme Designer...)
3. In the "Main Background Image" dropdown, select your image
4. Adjust transparency using the slider
5. Click Apply or Save to see changes

Your images will appear in the Theme Designer and can be saved as part of custom presets!
