About Morse Code

Morse code is a method used in telecommunication to encode text characters as standardized sequences of two different signal durations, called dots and dashes.

Morse Code Examples:
A = .-
B = -...
C = -.-.
1 = .----
. = .-.-.-
Space = /

About HTML Character References

HTML Character References allow you to display special characters, symbols, and non-ASCII characters in HTML documents. They include numeric (decimal/hex) and named references.

HTML Entity Examples:
&amp; → &
&lt; → <
&copy; → ©
&#232; → è (decimal)
&#xE8; → è (hex)
&#128512; → 😀

About Unicode-256

Unicode-256 refers to the first 256 code points of the Unicode standard, which includes basic Latin letters, numbers, punctuation, and some special characters. Each character is assigned a unique decimal number from 0 to 255.

Unicode-256 Examples:
A = 65
B = 66
Space = 32
! = 33
č = 269 (Croatian letter)
Ž = 381 (Croatian letter)

About Brainfuck

Brainfuck is an esoteric programming language created in 1993 by Urban Müller. It consists of only eight simple commands and is designed for extreme minimalism.

Brainfuck Commands:
> = Move pointer right
< = Move pointer left
+ = Increment current cell
- = Decrement current cell
. = Output character at current cell
, = Input character to current cell
[ = Start loop
] = End loop

Croatian Letters Support

This translator fully supports Croatian letters (č, ć, đ, š, ž) in all translation directions. For Morse code, Croatian letters are converted to their closest Latin equivalents:

Croatian Letter Mapping:
Č, Ć → C (Morse: -.-.)
Đ → D (Morse: -..)
Š → S (Morse: ...)
Ž → Z (Morse: --..)

In HTML Entities, Unicode-256, and Brainfuck, Croatian letters use their full Unicode values.
