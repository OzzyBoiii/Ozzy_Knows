Distance from a Point to a Line

The distance from a point to a line is the shortest distance between the point and any point on the line. To find this distance:

  1. Drop a perpendicular from the point to the line
  2. Find the intersection point P of this perpendicular with the line
  3. The distance is the length of the segment TP

Given a point T(x₀,y₀) and a line Ax + By + C = 0, the distance d is calculated by:

d = |Ax₀ + By₀ + C| / √(A² + B²)

This formula can be verified by considering the area of the triangle formed by the line and the coordinate axes, or through vector projection methods.

Example Calculation

Given point T(2,3) and line 3x + 4y - 5 = 0:

d = |3×2 + 4×3 - 5| / √(3² + 4²)
d = |6 + 12 - 5| / √(9 + 16)
d = |13| / √25
d = 13 / 5 = 2.6

Geometric Derivation

This formula can be verified by considering the area of the triangle formed by the line and the coordinate axes. The line Ax + By + C = 0 intersects the x-axis at M(-C/A, 0) and the y-axis at N(0, -C/B).

The area of triangle MTN can be calculated in two ways:

Area = 1/2 |(-C/A)(-C/B - y₀) + x₀·(C/B)| = 1/2 |(C/AB)(Ax₀ + By₀ + C)|

Alternatively, using the distance formula:

Area = 1/2 × |MN| × d = 1/2 × √(C²/A² + C²/B²) × d

Setting these equal gives:

1/2 × |C/AB| × |Ax₀ + By₀ + C| = 1/2 × |C/AB| × √(A² + B²) × d

Which simplifies to the distance formula.
