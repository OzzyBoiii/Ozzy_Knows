6. How to use external images (Option B)
You said you want to keep some images outside the vault and link to them. Example external path:

C:\Users\CrozzyBoii\Documents\VSCode_Programs\Ozzy_Knows\Course\Biology\Sections\1_Biosfera\Images\some_image.png

Because this is outside the Summaries vault, Obsidian cannot use ![[...]] to embed it directly. Instead, you will use file URLs or a plugin.
​

6.1. Simple file URL links (no plugin)
Windows file URL syntax:

text
file:///C:/Users/CrozzyBoii/Documents/VSCode_Programs/Ozzy_Knows/Course/Biology/Sections/1_Biosfera/Images/some_image.png
Note the three slashes after file: and forward slashes / in the path.
​

In a note, you can write:

text
[Slika biosfere](file:///C:/Users/CrozzyBoii/Documents/VSCode_Programs/Ozzy_Knows/Course/Biology/Sections/1_Biosfera/Images/some_image.png)
This shows as a clickable link “Slika biosfere”.

Clicking it opens the image in your default image viewer (not embedded inside the note).

If you want it to look more “visual”, you can also paste the URL as plain text; many themes/plugins can detect and make it clickable.

6.2. Optional: plugin for external embeds
If one day you decide you really want external images embedded in the note, not just linked, you can look at plugins like External File Embed and Link.
​

It lets you embed local files outside the vault with a special syntax.

For now, you can stay with pure Markdown + file URLs which is simpler.

7. Linking internal images (inside Summaries)
For any images that you do store inside the vault (e.g. new screenshots you paste), treat them normally:

Decide where in the vault you’ll keep internal images, for example:

text
Summaries\
  Biologija\
    Text Summaries.md
    Images\
      bio_img_1.png
      bio_img_2.png
In Obsidian: Settings → Files & Links →

“Default location for new attachments” → choose In subfolder under current folder and set the subfolder name to Images.
​

This means if you paste an image while editing Biologija\Text Summaries.md, Obsidian creates/uses Biologija\Images\ automatically.

To embed these internal images in a Cornell note:

text
![[Biologija/Images/bio_img_1.png|250]]
or simply drag them from the file explorer into the note; Obsidian will insert the correct ![[...]] line.
​

Use internal images for things you want nicely embedded; use external file URLs for things you don’t want to move into the vault.
