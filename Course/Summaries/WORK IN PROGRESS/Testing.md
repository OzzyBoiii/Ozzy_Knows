## 1. Basic Definitions

A (real) function is a rule that assigns to each real number xx exactly one real number f(x)f(x).[](https://journeyinmath.wordpress.com/2017/08/05/most-beautiful-topics-in-high-school-math-calculus-part-1/)​

## 2. Quadratic Functions

## 2.1 General Form

A quadratic function in one variable is

f(x)=ax2+bx+c,a,b,c∈R, a≠0.f(x)=ax2+bx+c,a,b,c∈R, a=0.

Key facts:[](https://journeyinmath.wordpress.com/2017/08/05/most-beautiful-topics-in-high-school-math-calculus-part-1/)​

- If a>0a>0, the parabola opens upward.
    
- If a<0a<0, the parabola opens downward.
    
- The graph is symmetric about a vertical line called the **axis** of symmetry.
    

---

## 2.2 Vertex Form

Any quadratic can be written in vertex form

f(x)=a(x−h)2+k,f(x)=a(x−h)2+k,

where (h,k)(h,k) is the vertex of the parabola.[](https://journeyinmath.wordpress.com/2017/08/05/most-beautiful-topics-in-high-school-math-calculus-part-1/)​

The conversion from standard form uses

h=−b2a,k=f(h)=f ⁣(−b2a).h=−2ab,k=f(h)=f(−2ab).

## 3. A Simple Theorem

## 3.1 Location of the Vertex

**Theorem (Vertex formula).**  
For f(x)=ax2+bx+cf(x)=ax2+bx+c with a≠0a=0, the graph has a vertex at

(−b2a, f ⁣(−b2a)).(−2ab, f(−2ab)).

_Sketch of proof._  
Complete the square:

ax2+bx+c=a[x2+bax]+c=a[(x+b2a)2−(b2a)2]+c.ax2+bx+c=a[x2+abx]+c=a[(x+2ab)2−(2ab)2]+c.

Then

f(x)=a(x+b2a)2+(c−b24a),f(x)=a(x+2ab)2+(c−4ab2),

so the vertex is at x=−b2ax=−2ab.[](https://www.math.utoronto.ca/karshon/courses/mat1344/latex-samplefile.pdf)​

## 4. Discriminant and Roots

## 4.1 Quadratic Formula

Solutions of ax2+bx+c=0ax2+bx+c=0 are

x=−b±b2−4ac2a,x=2a−b±b2−4ac,

and the discriminant is D=b2−4acD=b2−4ac.[](https://www.math.utoronto.ca/karshon/courses/mat1344/latex-samplefile.pdf)​

- If D>0D>0: two distinct real roots.
    
- If D=0D=0: one real root (double root).
    
- If D<0D<0: no real roots, two complex roots.
