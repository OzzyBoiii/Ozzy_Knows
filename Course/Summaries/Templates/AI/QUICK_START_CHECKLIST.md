# ✅ LOVRIN CORNELL - Quick Start Checklist

## 🎯 Complete This in 15 Minutes!

---

## Step 1: Install CSS (2 minutes)

- [ ] Open your vault folder in file explorer
- [ ] Navigate to `.obsidian/snippets/`
- [ ] Create `snippets` folder if it doesn't exist
- [ ] Copy `lovrin-cornell-ultimate.css` into snippets folder
- [ ] In Obsidian: Settings → Appearance → CSS snippets
- [ ] Click refresh icon (↻)
- [ ] Enable "lovrin-cornell-ultimate"
- [ ] **DISABLE all other Cornell CSS snippets**
- [ ] Restart Obsidian (Ctrl+R or Cmd+R)

---

## Step 2: Install Essential Plugins (5 minutes)

Go to: Settings → Community Plugins → Browse

### Must-Have Plugins:
- [ ] **Templater** - Install + Enable
- [ ] **Dataview** - Install + Enable
- [ ] **LaTeX Suite** - Install + Enable
- [ ] **Advanced Tables** - Install + Enable
- [ ] **Excalidraw** - Install + Enable

### Quick Plugin Settings:

**Templater:**
- [ ] Template folder location: `Templates/`
- [ ] ✓ Trigger Templater on new file creation

**LaTeX Suite:**
- [ ] ✓ Trigger on TAB
- [ ] Import snippets: `.obsidian/latex-suite-snippets.json`

**Dataview:**
- [ ] ✓ Enable JavaScript queries
- [ ] ✓ Enable inline queries

---

## Step 3: Set Up Template (3 minutes)

- [ ] Copy `Lovrin_Cornell_Ultimate.md` to your `Templates/` folder
- [ ] Create `Templates/` folder if it doesn't exist
- [ ] Verify Templater points to correct folder

---

## Step 4: Import LaTeX Snippets (2 minutes)

- [ ] Copy `latex-suite-snippets.json` to `.obsidian/` folder
- [ ] Settings → LaTeX Suite
- [ ] Scroll to "Snippets" section
- [ ] Click "Import snippets"
- [ ] Select: `.obsidian/latex-suite-snippets.json`
- [ ] Confirm import (should see "Imported X snippets")

---

## Step 5: Test Everything (3 minutes)

### Test 1: Create New Note
- [ ] Create new note
- [ ] Command Palette (Ctrl+P): "Templater: Insert Template"
- [ ] Select "Lovrin_Cornell_Ultimate"
- [ ] Fill in prompts
- [ ] Note should have proper structure

### Test 2: LaTeX Works
- [ ] In your test note, type: `alpha` + TAB
- [ ] Should expand to: `\alpha`
- [ ] Type: `//` + TAB
- [ ] Should create: `\frac{}{}`

### Test 3: CSS Layout Works
- [ ] Check if note has two columns
- [ ] Left: text content
- [ ] Right: visual content section
- [ ] Cue callouts in left margin

### Test 4: Table Formatting
- [ ] Create simple table: `| A | B |`
- [ ] Press TAB
- [ ] Should auto-format and move to next cell

---

## 🎉 You're Done!

If all tests passed, you're ready to take notes!

---

## 🐛 Common First-Time Issues

### CSS not working
- **Fix**: Make sure snippet is enabled AND Obsidian restarted

### LaTeX not expanding
- **Fix**: JSON must be imported in LaTeX Suite settings

### Template not found
- **Fix**: Check Templater folder path matches your Templates folder

### Columns not showing
- **Fix**: Note must have `lovrin-cornell` in cssclasses frontmatter

## ✨ Pro Tips

1. **Start simple**: Don't fill every section right away
2. **Use cues**: Add `> [!cue] Topic` callouts as you write
3. **Separate content**: Text on left, visuals on right - stick to it!
4. **Link notes**: Use `[[links]]` to connect ideas
5. **Review summary**: Update bottom summary as you finish sections
