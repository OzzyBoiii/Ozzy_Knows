
● Usporedivost realnih brojeva  
    ● Za svaka dva realna broja vrijedi ili a < b ili a > b ili a = b  
○ Uspoređivanje brojeva  
    ● Broj a manji je od broja b ako i samo ako je a - b < 0  
    ○ Ovoj definiciji ekvivalentna je sljedeća definicija  
    ● Broj a manji je od broja b onda i samo onda ako postoji pozitivan broj k za koji je a + k = b  
    ● Primjerice, broj 7 manji je od broja 12 jer je 12 - 7 = 5 > 0  
    ● Broju 7 valja dodati 5 kako bi se dobilo 12  
    ● Broj -111 manji je od broja -99, jer je -99 - (-111) = 12 > 0  
    ● Broju -111 treba dodati 12 da bi se dobio broj -99  
    ● Broj -0,42 veći je od broja -0,815 jer je -0,42 - (-0,815) = 0,395 > 0  
    ○ Ili: broj -0,815 manji je od broja -0,42 jer broju -0,815 treba dodati pozitivan broj 0,395 kako bi se dobio -0,42  
○ Uspoređivanje racionalnih brojeva  
    ● Neka su a/b i c/d razlomci s pozitivnim nazivnicima (b > 0 i d > 0) i pretpostavimo da vrijedi a/b > c/d  
    ● Tada možemo pisati a/b - c/d = (ad - bc)/bd > 0, pa zaključujemo: kako je bd > 0, onda je i ad - bc > 0, odnosno ad > bc  
    ● Dakle, nejednakost a/b > c/d, gdje je b > 0 i d > 0, ekvivalentna je nejednakosti ad > bc  
    ● Ako su racionalni brojevi a/b i c/d napisani u standardnom obliku (s pozitivnim nazivnicima), tada vrijedi a/b > c/d ⇔ ad > bc  
○ Svojstva relacije uređaja  
    ● Tranzitivnost relacije uređaja  
        ○ Ako su a, b i c realni brojevi, onda iz a < b i b < c slijedi a < c  
        ○ Dokažimo ovo svojstvo  
        ○ Iz a < b slijedi da postoji pozitivan broj m takav da je a + m = b  
        ○ Iz b < c slijedi da postoji pozitivan broj n takav da je b + n = c  
        ○ Zbrojimo li dvije dobivene jednakosti, imat ćemo a + m + b + n = b + c, odnosno a + (m + n) = c, gdje je m + n pozitivan broj  
        ○ Slijedi a < c  
    ● Usklađenost relacije uređaja sa zbrajanjem  
        ○ Neka su a i b realni brojevi  
        ○ Tada je a < b onda i samo onda ako je a + c < b + c, za svaki realni broj c  
        ○ Kažemo još: dodamo li na obje strane nejednakosti isti broj, nejednakost se neće promijeniti  
        ○ Iz a < b slijedi da postoji pozitivan broj p takav da je a + p = b  
        ○ Dodamo li na obje strane ove jednakosti broj c, jednakost se neće promijeniti: a + p + c = b + c, odnosno (a + c) + p = b + c, što znači da je a + c < b + c  
        ○ Time smo pokazali da iz a < b slijedi a + c < b + c, pri čemu c može biti bilo koji realni broj  
        ○ Obratno, dodavanjem broja -c na obje strane nejednakosti a + c < b + c dobit ćemo a + c + (-c) < b + c + (-c), tj. a < b  
        ○ Ovim je ovo svojstvo relacije uređaja dokazano  
    ● Usklađenost relacije uređaja s množenjem  
        ○ Neka su a i b realni brojevi takvi da je a < b  
        ○ Ako je c > 0, onda je ac < bc  
        ○ Ako je c < 0, onda je ac > bc  
        ○ Kažemo još: pomnožimo li nejednakost dvaju realnih brojeva pozitivnim brojem, znak nejednakosti neće se promijeniti; pomnožimo li je negativnim brojem, znak nejednakosti će se promijeniti  
        ○ Dokažimo ovo svojstvo  
        ○ Iz a < b slijedi da postoji pozitivan broj p takav da je a + p = b  
        ○ Pomnožimo ovu jednakost pozitivnim brojem c, tada je ac + pc = bc  
        ○ Kako je pc > 0, slijedi da je i ac < bc  
        ○ Iz a < b slijedi da postoji pozitivan broj p takav da je a + p = b  
        ○ Pomnožimo ovu jednakost negativnim brojem c, tada je ac + pc = bc, odnosno ac = bc + p(-c)  
        ○ No kako je p(-c) > 0, onda je ac > bc  
○ Intervali  
    ● Nejednakostima kao što su x < a, x > b, c < x < d i sličnim određeni su podskupovi skupa realnih brojeva  
    ● Takve podskupove zovemo intervali  
    ● Skup realnih brojeva x takvih da je x > a jest interval i zapisujemo ga kao ⟨a, +∞⟩  
    ● Zapis +∞ ne predstavlja broj, već simbol  
    ● Koristimo ga da naglasimo da interval sadrži sve brojeve veće od a  
    ● Tako je, primjerice, ⟨-1, +∞⟩ skup svih realnih brojeva većih od -1  
    ● Taj interval zorno prikazujemo na brojevnom pravcu tako da iscrtamo onaj dio pravca kojem pripadaju sve točke T(x) za koje je x > -1 (SLIKA 1)  
    ● U svim trima navedenim primjerima rubovi intervala ne pripadaju intervalu  
    ● Tako u skupu ⟨-1, +∞⟩ nije broj -1, već samo brojevi veći od -1  
    ● Intervalu ⟨-∞, 3⟩ ne pripada broj 3, niti su u skupu ⟨-1/2, 3/4⟩ brojevi -1/2 i 3/4  
    ● Za ovakve intervale kažemo da su otvoreni  
    ● Uz relaciju uređaja „<“ mi ćemo rabiti i relaciju uređaja „≤“ (manje ili jednako)  
    ● a ≤ b onda i samo onda ako je a < b ili a = b  
    ● Tom relacijom bilježimo slučaj kada i rub intervala pripada intervalu, što u zapisu intervala naznačujemo uglatom zagradom  
    ● Primjerice, s [-2, 3] zapisan je skup realnih brojeva x, -2 ≤ x ≤ 3, dakle njemu pripadaju oba ruba  
    ● Za takav interval kažemo da je zatvoren  
    ● S [-2, 3⟩ zapisan je skup realnih brojeva x, -2 ≤ x < 3, dakle njemu pripada samo lijevi rub, broj -2, ali ne i desni, broj 3  
    ● Za takav interval kažemo da je poluotvoren  
    ● Poluotvoren je i interval oblika ⟨-2, 3]  
    ● Vrste intervala: otvoreni, zatvoreni, poluotvoreni, beskonačni intervali (SLIKA 2)

○ Apsolutna vrijednost realnog broja  
    ● Za dani realni broj x njegova je apsolutna vrijednost (modul) broj |x| koji određujemo na sljedeći način:  
    |x| = { x, ako je x ≥ 0; -x, ako je x < 0 }  
    ● Dakle: ako je broj x pozitivan ili nula, tada je on jednak svojoj apsolutnoj vrijednosti  
    ● Za svaki x ≥ 0 vrijedi |x| = x  
    ● Ako je x negativan broj, njegova apsolutna vrijednost je suprotan broj -x koji je pozitivan  
    ● Za svaki x < 0 je |x| = -x  
    ● Primjeri:  
        ○ |√3| = √3  
        ○ | -2/3 | = 2/3  
        ○ |0| = 0  
    ● Drugi korijen iz realnog broja povezan je s apsolutnom vrijednošću na sljedeći način: √(a²) = |a|  
    ● Drugi korijen iz pozitivnog broja uzimamo kao pozitivan broj  
○ Svojstva apsolutne vrijednosti  
    ● Za sve realne brojeve a i b vrijede sljedeće tvrdnje:  
        ○ Apsolutne vrijednosti suprotnih brojeva su jednake: |a| = |-a|  
        ○ Apsolutna vrijednost zbroja dvaju brojeva manja je ili jednaka zbroju apsolutnih vrijednosti tih brojeva (nejednakost trokuta): |a + b| ≤ |a| + |b|  
        ○ Apsolutna vrijednost umnoška dvaju brojeva jednaka je umnošku apsolutnih vrijednosti tih brojeva: |ab| = |a| · |b|  
        ○ Apsolutna vrijednost količnika dvaju brojeva jednaka je količniku apsolutnih vrijednosti tih brojeva, za broj b ≠ 0 vrijedi: |a/b| = |a| / |b|  
    ● Graf funkcije f(x) = |x|  
        ○ Promatramo li apsolutnu vrijednost realnog broja kao funkciju, uočit ćemo da je bliska linearnoj funkciji  
        ○ Za sve pozitivne brojeve x i nulu vrijedi |x| = x, za negativne brojeve |x| = -x  
        ○ Tako možemo zapisati: f(x) = |x| = { x, x ≥ 0; -x, x < 0 }  
        ○ Graf ove funkcije sastoji se iz dviju grana, dvaju polupravaca koji se sastaju u ishodištu koordinatnog sustava (SLIKA 3)  
        ○ S grafa možemo očitati najvažnija svojstva ove funkcije  
        ○ Tako uočavamo da je čitav graf smješten iznad osi x – jer su apsolutne vrijednosti nenegativne – i da je graf simetričan prema osi y jer |x| = |-x|  
○ Udaljenost točaka na brojevnom pravcu  
    ● Položaj neke točke na brojevnom pravcu jednoznačno je određen jednim realnim brojem, njezinom koordinatom  
    ● Koordinata x₁ točke T₁ s desne strane ishodišta pozitivan je broj x₁ koji predstavlja udaljenost te točke od ishodišta koordinatnog sustava  
    ● Od ishodišta je jednako udaljena i točka T₂ s koordinatom x₂ = -x₁  
    ● Udaljenost točke T₂ od ishodišta jednaka je -x₂  
    ● Općenito, za bilo koju točku T(x) brojevnog pravca, njezina je udaljenost od ishodišta nenegativan broj |x|, pa vrijedi |OT| = |x|  
    ● Kako na brojevnom pravcu odrediti točke za koje vrijedi |x| = a  
        ○ Kako na brojevnom pravcu odrediti točku T(x) za koju vrijedi |x| = a, gdje je a pozitivan broj?  
        ○ Drugim riječima, treba odrediti onu točku čija je udaljenost od ishodišta koordinatnog sustava jednaka a  
        ○ Dvije su takve točke, T₁(-a) i T₂(a)  
        ○ One su simetrične u odnosu na ishodište  
    ● Neka su T₁(x₁) i T₂(x₂) dvije točke brojevnog pravca  
    ● Tada je udaljenost tih dviju točaka jednaka |T₁ T₂| = |x₂ - x₁|

○ Jednadžbe i nejednadžbe s apsolutnim vrijednostima  
    ● Jednadžba oblika |x| = a najjednostavnija je jednadžba u kojoj se pojavljuje apsolutna vrijednost realnog broja  
        ○ Ako je a < 0, ta jednadžba nema rješenja jer je tada broj s lijeve strane nenegativan, a broj s desne strane negativan  
        ○ Ako je a = 0, jednadžba |x| = a ima jedinstveno rješenje x = 0  
        ○ Ako je a > 0, tada su rješenja jednadžbe suprotni brojevi x₁ = a i x₂ = -a

    ● Nejednadžbe s apsolutnim vrijednostima  
        ○ Kako se rješavaju nejednadžbe s apsolutnim vrijednostima?  
        ○ U suštini valja razmotriti dva osnovna tipa takvih nejednadžbi, koja su utemeljena na sljedećim činjenicama (za a > 0):  
            ● |x| < a onda i samo onda ako je -a < x < a  
            ● |x| > a onda i samo onda ako je x < -a ili x > a  
        ○ To se može obrazložiti tumačenjem preko udaljenosti točaka na brojevnom pravcu: |x| je udaljenost točke s koordinatom x od ishodišta, pa |x| < a znači da su točke na udaljenosti manjoj od a (unutar intervala), a |x| > a da su točke na udaljenosti većoj od a (izvan tog „kruga“)
