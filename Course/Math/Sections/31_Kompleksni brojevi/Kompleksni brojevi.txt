● Algebarski prikaz kompleksnog broja  
   ○ Dosad smo upoznali četiri skupa brojeva: prirodne, cijele, racionalne i realne brojeve  
   ○ Znamo također da vrijedi N ⊂ Z ⊂ Q ⊂ R  
   ○ Svaki od skupova Z, Q i R proširenje je prethodnog  
   ○ To je proširenje načinjeno zbog potrebe da se omogući provedba određene algebarske operacije  
   ○ Primjerice, razlika dvaju prirodnih brojeva nije općenito prirodan broj  
   ○ Stoga se skup N proširuje negativnim cijelim brojevima i nulom te se tako dobije skup cijelih brojeva Z  
   ○ Zbog izvedivosti dijeljenja cijelih brojeva, skup Z proširuje se razlomcima odnosno periodičkim decimalnim brojevima, čime dobivamo skup racionalnih brojeva Q  
   ○ Skup realnih brojeva R proširuje skup Q dodajući mu iracionalne brojeve, sve decimalne neperiodičke brojeve  
   ○ Skup R nije završetak ovog procesa  
   ○ Neke jednostavne jednadžbe, poput x² + x + 1 = 0, nemaju rješenja u skupu realnih brojeva  
   ○ Primjerice, već odgovor na pitanje: Za koji realan broj x vrijedi x² = -1? glasi: ne postoji takav realan broj

● Algebarske operacije  
   ○ Za operacije zbrajanja i množenja kompleksnih brojeva zahtijevamo da imaju uobičajena svojstva, za sve kompleksne brojeve z₁, z₂, z₃:  

● Svojstva zbrajanja i množenja u skupu C  
   ○ Svojstvo komutativnosti za zbrajanje i množenje:  
      ○ z₁ + z₂ = z₂ + z₁  
      ○ z₁ ⋅ z₂ = z₂ ⋅ z₁  
   ○ Svojstvo asocijativnosti za zbrajanje i množenje:  
      ○ z₁ + (z₂ + z₃) = (z₁ + z₂) + z₃  
      ○ z₁ ⋅ (z₂ ⋅ z₃) = (z₁ ⋅ z₂) ⋅ z₃  
   ○ Svojstvo distributivnosti množenja prema zbrajanju:  
      ○ z₁ ⋅ (z₂ + z₃) = z₁ ⋅ z₂ + z₁ ⋅ z₃  

● Sad primjerice za z₁ = x₁ + y₁ i, z₂ = x₂ + y₂ i imamo:  
   ○ z₁ + z₂ = (x₁ + y₁ i) + (x₂ + y₂ i) = x₁ + y₁ i + x₂ + y₂ i = x₁ + x₂ + (y₁ + y₂)i = (x₁ + x₂) + (y₁ + y₂)i  
   ○ U ovom smo računu koristili asocijativnost i komutativnost za zbrajanje te na koncu distributivnost, i na taj smo način izveli formulu za zbrajanje kompleksnih brojeva  
   ○ S pomoću zbrajanja i množenja možemo iskazati i izvedene algebarske operacije oduzimanja i dijeljenja  
   ○ Primjerice, razlika dvaju kompleksnih brojeva definira se ovako:  
      ○ z₁ - z₂ := z₁ + (-1)z₂  
   ○ S desne su strane ove jednakosti korištene samo operacije množenja i zbrajanja  

● Zbroj, razlika i umnožak kompleksnih brojeva  
   ○ Ako su z₁ = x₁ + y₁ i i z₂ = x₂ + y₂ i bilo koja dva kompleksna broja, tada njihov zbroj, razliku i umnožak računamo na sljedeći način:  
      ○ z₁ + z₂ = x₁ + x₂ + (y₁ + y₂)i  
      ○ z₁ - z₂ = x₁ - x₂ + (y₁ - y₂)i  
      ○ z₁ ⋅ z₂ = (x₁ x₂ - y₁ y₂) + (x₁ y₂ + x₂ y₁)i  
   ○ Formulu za računanje umnoška ne treba pamtiti, već se dva broja množe poput algebarskih izraza, uvažavajući činjenicu da je i² = -1

● PRONAĐI GREŠKU  
   ○ Pronađi pogrešku u sljedećem rasuđivanju ili priznaj da je 1 = -1  
      ○ Vrijedi identitet √(-c) = i√c, gdje je c realan broj  
      ○ Tako za sve realne brojeve x i y imamo √(x - y) = i√(y - x)  
      ○ Stavivši ovdje x = a, y = b dobivamo √(a - b) = i√(b - a)   (*)  
      ○ Za x = b, y = a dobivamo pak √(b - a) = i√(a - b)   (**)  
      ○ Množeći jednakosti (*) i (**) dobivamo √(a - b) · √(b - a) = i² √(b - a) · √(a - b)  
      ○ Odavde, nakon kraćenja s √(a - b) · √(b - a) dobivamo 1 = i², odnosno, 1 = -1  
      ○ (Greška je u proizvoljnom korištenju svojstava korijena za kompleksne brojeve kao da se radi o pozitivnim realnim brojevima i u nevaljanom kraćenju kada izraz može biti 0)

● Kompleksna ravnina  
   ○ Svakom kompleksnom broju z = x + yi odgovara uređeni par realnih brojeva (x, y)  
   ○ Svaki kompleksni broj stoga možemo zapisati u obliku uređenog para (x, y) realnih brojeva  
   ○ Primjerice: -1 + 2i = (-1, 2), 3 + 7i = (3, 7), -9i = (0, -9), 4 = (4, 0)  
   ○ Ovakvo zapisivanje kompleksnih brojeva nameće pomisao da bi se kompleksnim brojevima mogle pridružiti točke u koordinatnoj ravnini  
   ○ Takvo je pridruživanje obostrano jednoznačno, svakom je kompleksnom broju jednoznačno pridružena točka i svakoj točki odgovara točno jedan kompleksni broj  
   ○ Tako skup C možemo poistovjetiti s ravninom u koju je uveden Kartezijev koordinatni sustav  
   ○ Os x koordinatnog sustava zove se realna os u C  
      ○ Na njoj (i samo na njoj) leže realni brojevi  
   ○ Os y naziva se imaginarna os i ona sadrži imaginarne brojeve  
   ○ Koordinatna ravnina u kojoj su na opisani način smješteni svi kompleksni brojevi zove se kompleksna ravnina ili Gaussova ravnina  

● Kompleksna ili Gaussova ravnina

   ○ Na osi apscisa smješteni su realni brojevi pa se ona zove realna os  
   ○ Na osi ordinata smješteni su imaginarni brojevi pa se ona zove imaginarna os  
   ○ Pridruživanje kompleksnih brojeva i točaka kompleksne ravnine obostrano je jednoznačno

● Svojstva modula  
   ○ Modul kompleksnog broja ima sljedeća svojstva:  
      ● Modul umnoška dvaju kompleksnih brojeva jednak je umnošku njihovih modula: |z₁ · z₂| = |z₁| · |z₂|  
         ○ Provjerimo ovu jednakost:  
            ○ |z₁ · z₂| = |(x₁ + y₁ i) · (x₂ + y₂ i)| = |(x₁ x₂ - y₁ y₂) + (x₁ y₂ + x₂ y₁)i|  
            ○ = √((x₁ x₂ - y₁ y₂)² + (x₁ y₂ + x₂ y₁)²) = √(x₁² x₂² + y₁² y₂² + x₁² y₂² + x₂² y₁²)  
            ○ = √((x₁² + y₁²) · (x₂² + y₂²)) = √(x₁² + y₁²) · √(x₂² + y₂²) = |z₁| · |z₂|  
         ○ Navedeno se svojstvo indukcijom poopćava na umnožak bilo koliko kompleksnih brojeva  
         ○ Općenito je: |z₁ · z₂ · … · zₙ| = |z₁| · |z₂| · … · |zₙ|  
         ○ Ako su svi faktori umnoška jednaki, tada je |zⁿ| = |z|ⁿ  
      ● Modul količnika dvaju kompleksnih brojeva jednak je količniku njihovih modula: |z₁ / z₂| = |z₁| / |z₂|, z₂ ≠ 0  
         ○ Dokažimo ovu jednakost  
         ○ Najprije primijetimo da je recipročna vrijednost kompleksnog broja z = x + yi jednaka 1/z = 1/(x + yi) = x/(x² + y²) - y/(x² + y²) i  
         ○ Pa je |1/z| = √(x²/(x² + y²)² + y²/(x² + y²)²) = √((x² + y²)/(x² + y²)²) = 1/√(x² + y²) = 1/|z|  
         ○ I sada imamo: |z₁ / z₂| = |z₁ · 1/z₂| = |z₁| · |1/z₂| = |z₁| · 1/|z₂| = |z₁| / |z₂|  

● Modul kompleksnog broja  
   ○ Modul kompleksnog broja z = x + yi je realan broj |z| koji se definira formulom: |z| = √((Re z)² + (Im z)²) = √(x² + y²)  
   ○ Za modul kompleksnog broja vrijedi:  
      ○ |z₁ · z₂| = |z₁| · |z₂|  
      ○ |zⁿ| = |z|ⁿ  
      ○ |z₁ / z₂| = |z₁| / |z₂|, z₂ ≠ 0

● Polarni sustav  
   ○ Neka je M(x, y) točka Gaussove ravnine koja odgovara broju z = x + yi, pri čemu je z ≠ 0  
   ○ Položaj točke M u ravnini obično opisujemo njezinim Kartezijevim koordinatama, a dobivamo ih ortogonalnim projiciranjem te točke na koordinatne osi  
   ○ Međutim, ista se točka može zadati i s pomoću druga dva podatka:  
      ● udaljenosti r točke do ishodišta O  
      ● kuta φ između spojnice OM i pozitivnog dijela x-osi  
   ○ Položaj točke M opisuju Kartezijeve koordinate (x, y), ali i polarne koordinate (r, φ)  
   ○ Broj r je realan pozitivan broj, a za mjeru kuta φ uzimamo vrijednost unutar intervala [0, 2π⟩  
   ○ r i φ nazivaju se polarne koordinate kompleksnog broja z

● Koordinatna mreža  
   ○ Koordinatna krivulja u nekom sustavu obuhvaća sve točke kod kojih je jedna od koordinata stalna, dok se druga mijenja uzimajući sve moguće vrijednosti  
   ○ Tako je primjerice u Kartezijevu sustavu pravac {(x, y) : x = 2} koordinatna krivulja: duž tog pravca prva je koordinata konstantna (i iznosi 2), a druga nije zadana i možemo je odabrati po volji  
   ○ U Kartezijevu sustavu koordinatne krivulje čine pravci x = C₁ (prva koordinata stalna) te y = C₂ (druga koordinata stalna)  
      ○ Pritom vrijednosti konstanti C₁ i C₂ mogu biti uzete po volji  
   ○ Kartezijeva koordinatna mreža (lijevo)  
      ○ Presjek dviju koordinatnih krivulja određuje položaj točke u ravnini (desno)  
      ○ Svaka točka u ravnini leži na presjeku točno dviju koordinatnih krivulja  
      ○ Tako primjerice, točka M(2, -3) leži na presjeku dviju koordinatnih krivulja: pravaca x = 2 i y = -3  

   ○ Kako izgledaju koordinatne krivulje u polarnom sustavu?  
      ○ Na prvoj koordinatnoj krivulji konstantna je udaljenost r, a kut φ mijenja se po volji  
         ○ Stoga je njena jednadžba r = C₁  
         ○ Ta krivulja predstavlja kružnicu polumjera C₁ sa središtem u ishodištu  
      ○ Na drugoj koordinatnoj krivulji čvrst je kut φ, a udaljenost se mijenja po volji  
         ○ Njezina je jednadžba φ = C₂ i ona predstavlja zraku iz ishodišta  
   ○ Polarna koordinatna mreža u ravnini (lijevo)  
      ○ Svaka točka (osim ishodišta) leži na presjeku točno jedne kružnice i jedne zrake (desno)  
      ○ Svake dvije koordinatne krivulje određuju, u svom presjeku, položaj jedne točke u ravnini  
      ○ Jedino se u ishodištu siječe beskonačno mnogo zraka, tu iznos kuta φ nije određen, ali samo za tu točku vrijedi r = 0

● Trigonometrijski prikaz kompleksnog broja  
   ○ Kartezijeve i polarne koordinate vezane su relacijama:  
      ○ x = r cos φ  
      ○ y = r sin φ   (1)  
   ○ Prikaz kompleksnog broja z u obliku:  
      ○ z = x + iy = r(cos φ + i sin φ)   (2)  
      ○ naziva se trigonometrijski prikaz broja z  
   ○ Udaljenost r kompleksnog broja od ishodišta je modul tog broja:  
      ○ r = |z| = √(x² + y²)   (3)  
   ○ Kut φ nazivamo argument kompleksnog broja i označavamo s φ = arg(z) te ga određujemo iz veze:  
      ○ tan φ = y / x   (4)  

● Veza između Kartezijevih i polarnih koordinata  
   ○ Jednadžbom (4) kut φ nije potpuno određen  
   ○ Naime, ova jednadžba ima dva rješenja unutar intervala [0, 2π⟩ (koja se međusobno razlikuju za π)  
   ○ Koje je od njih "pravo", određujemo s pomoću predznaka brojeva x i y, odnosno prema informaciji o kvadrantu u kojem se nalazi broj z  
   ○ Ako je x = 0, tada je broj imaginaran, pa je njegov argument π/2 za y > 0, odnosno 3π/2 za y < 0

● Množenje kompleksnih brojeva  
   ○ Trigonometrijski prikaz kompleksnog broja vrlo je pogodan za opis operacije množenja, a onda potenciranja i korjenovanja kompleksnih brojeva  
   ○ Izaberimo bilo koja dva kompleksna broja (različita od nule) i prikažimo ih u trigonometrijskom obliku:  
      ○ z₁ = r₁ (cos φ₁ + i sin φ₁)  
      ○ z₂ = r₂ (cos φ₂ + i sin φ₂)  
   ○ Koristeći se adicijskim teoremom za trigonometrijske funkcije, za njihov umnožak dobivamo izraz:  
      ○ z₁ z₂ = r₁ r₂ (cos φ₁ + i sin φ₁)(cos φ₂ + i sin φ₂)  
      ○ = r₁ r₂ [cos φ₁ cos φ₂ - sin φ₁ sin φ₂ + i(cos φ₁ sin φ₂ + sin φ₁ cos φ₂)]  
      ○ = r₁ r₂ [cos(φ₁ + φ₂) + i sin(φ₁ + φ₂)]   (5)  
   ○ Kao rezultat dobili smo trigonometrijski prikaz broja z₁ z₂  
      ○ Njegov je modul r₁ r₂, a argument φ₁ + φ₂  
      ○ Zato vrijedi:  
         ○ |z₁ z₂| = |z₁| · |z₂|   (6)  
         ○ arg(z₁ z₂) = arg z₁ + arg z₂   (7)  

● Množenje kompleksnih brojeva  
   ○ Kompleksni brojevi prikazani u trigonometrijskom obliku množe se tako da im se pomnože moduli, a argumenti zbroje:  
      ○ z₁ z₂ = r₁ r₂ [cos(φ₁ + φ₂) + i sin(φ₁ + φ₂)]  

===================================================  

● Potenciranje kompleksnih brojeva  
   ○ Pokazali smo da se kompleksni brojevi z₁ i z₂ množe ovako:  
      ○ z₁ z₂ = r₁ r₂ [cos(φ₁ + φ₂) + i sin(φ₁ + φ₂)]  
   ○ Uvrstimo ovdje z₁ = z₂ = z = r(cos φ + i sin φ)  
      ○ Dobivamo z² = r² (cos 2φ + i sin 2φ)  
   ○ Primjenom iste formule slijedi z³ = z² · z = r³ (cos 3φ + i sin 3φ)  
   ○ Indukcijom ćemo dobiti općenitu formulu  

● Potenciranje kompleksnih brojeva  
   ○ Potencija broja z napisanog u trigonometrijskom obliku računa se De Moivreovom formulom:  
      ○ zⁿ = rⁿ (cos nφ + i sin nφ)   (9)  
   ○ Iz nje čitamo:  
      ○ |zⁿ| = |z|ⁿ   (10)  
      ○ arg(zⁿ) = n arg z   (11)

● Dijeljenje kompleksnih brojeva  
   ○ Formula slična onoj za množenje vrijedi i za operaciju dijeljenja  
      ○ z₁ / z₂ = (r₁ (cos φ₁ + i sin φ₁)) / (r₂ (cos φ₂ + i sin φ₂))  
      ○ = r₁ / r₂ · (cos φ₁ + i sin φ₁) / (cos φ₂ + i sin φ₂) · (cos φ₂ - i sin φ₂) / (cos φ₂ - i sin φ₂)  
      ○ = r₁ / r₂ · (cos φ₁ + i sin φ₁) / (cos² φ₂ + sin² φ₂) (cos φ₂ - i sin φ₂)  
      ○ = r₁ / r₂ (cos φ₁ + i sin φ₁)(cos(-φ₂) + i sin(-φ₂))  
      ○ = r₁ / r₂ [cos(φ₁ - φ₂) + i sin(φ₁ - φ₂)]   (12)  
   ○ Iz ovog prikaza vidimo da je modul ovog broja r₁ / r₂, a argument φ₁ - φ₂:  
      ○ |z₁ / z₂| = |z₁| / |z₂|  
      ○ arg(z₁ / z₂) = arg z₁ - arg z₂   (13)  

● Dijeljenje kompleksnih brojeva  
   ○ Kompleksne brojeve dijelimo tako da im podijelimo module, a argumente oduzmemo:  
      ○ z₁ / z₂ = r₁ / r₂ [cos(φ₁ - φ₂) + i sin(φ₁ - φ₂)]

● Korjenovanje kompleksnih brojeva i n-ti korijen kompleksnog broja  
   ○ S pojmom korjenovanja upoznali smo se odavno, kad smo govorili da je to operacija inverzna operaciji potenciranja  
   ○ Međutim, ograničili smo se na korjenovanje pozitivnih realnih brojeva, pri čemu takav korijen ima samo jednu vrijednost i ta je vrijednost pozitivan realan broj  
      ○ Tako, primjerice, vrijedi √4 = 2, √5 ≈ 2,236… i sl  
      ○ Isto se događa za bilo koji parni korijen pozitivna broja, primjerice ¹²√16 = 2, ⁸√16 ≈ 1,587…  
      ○ Neparni korijen pozitivnog broja također ima samo jednu vrijednost  
      ○ Ovako definirane vrijednosti korijena nazivamo aritmetički korijen pozitivnog realnog broja  
   ○ Pojam korijena vezan je za rješavanje nekih jednadžbi  
      ○ Tako primjerice, jednadžba x² - 3 = 0 ima dva realna rješenja, od kojih je jedno √3, a drugo suprotnog predznaka, -√3  
      ○ S druge strane, jednadžba x² + 4 = 0 nema realnih rješenja  
   ○ Za neparni eksponent slična jednadžba imat će uvijek samo jedno realno rješenje  
      ○ Rješenje jednadžbe x³ = 8 je x = ³√8 = 2  
      ○ A rješenje jednadžbe x³ = -8 glasi x = -³√8 = -2  
   ○ U skupu kompleksnih brojeva situacija je drukčija  
      ○ Tamo jednadžba zⁿ - a = 0 ima uvijek točno n različitih rješenja  
      ○ Primjerice, jednadžba x² + 4 = 0 ima dva rješenja suprotnih predznaka: 2i i -2i  
      ○ A jednadžba x³ - 8 = 0 imat će tri rješenja: 2, -1 + i√3, -1 - i√3 (provjeri!)  
      ○ Jednadžba x⁴ - 16 = 0 ima četiri rješenja: 2, 2i, -2 i -2i  
   ○ Zato ćemo korijen kompleksnog broja definirati na drukčiji način

   ○ Odredimo sad n-ti korijen kompleksnog broja z, z ≠ 0  
      ○ Stavimo w = ⁿ√z, tj. z = wⁿ i prikažimo te brojeve u trigonometrijskom obliku:  
         ○ z = r(cos φ + i sin φ)  
         ○ w = ρ(cos ψ + i sin ψ)  
      ○ Tada iz r(cos φ + i sin φ) = ρⁿ (cos nψ + i sin nψ) slijedi:  
         ○ ρⁿ = r ⇒ ρ = ⁿ√r  
         ○ nψ = φ + 2kπ ⇒ ψ = (φ + 2kπ) / n  
      ○ U ovoj je formuli ⁿ√r aritmetički n-ti korijen pozitivnog broja r, to je pozitivan realan broj  
      ○ U izrazu za argument ψ, k uzima sve cjelobrojne vrijednosti  
      ○ No to ne znači da ćemo dobiti beskonačno mnogo različitih vrijednosti za argument ψ jer će se nakon nekog vremena te vrijednosti razlikovati za višekratnik od 2π, pa će stoga definirati isti argument  
      ○ Uvrštavanjem redom za k = 0, 1, …, n - 1 dobivamo sljedeće različite vrijednosti argumenta ψ:  
         ○ φ / n, (φ + 2π) / n, …, (φ + 2(n-1)π) / n  
      ○ Prva sljedeća vrijednost je (φ + 2nπ) / n = φ / n + 2π i ona daje isti argument kao i φ / n  
      ○ Sve sljedeće vrijednosti mogu se također dobiti iz gornjih vrijednosti dodavanjem višekratnika broja 2π  
      ○ Isto vrijedi i za negativne brojeve k
